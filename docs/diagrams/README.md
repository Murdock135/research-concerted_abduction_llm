# Pipeline diagrams

Standalone Mermaid sources for the diagrams in [How it works](../How%20it%20works.md).

| Diagram | File | Purpose |
|---|---|---|
| Pipeline overview | [pipeline-overview.mmd](pipeline-overview.mmd) | Flu/COVID example showing frame extraction, focal sets, belief masses, and DST combination. |
| Inputs and outputs | [pipeline-inputs-outputs.mmd](pipeline-inputs-outputs.mmd) | Input–process–output view of the four pipeline stages, with synthetic data generation shown separately as experiment preparation. |

The `.mmd` files contain Mermaid source without Markdown fences and can be opened
in a Mermaid-compatible editor or used for export. The diagrams also remain
embedded in `How it works.md`; when editing one, update its counterpart there.

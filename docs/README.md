2. [architecture.md](architecture.md) — pipeline stages, modules, how data flows through the code
3. [data_model.md](data_model.md) — the `DataSample` / `DataSet` schema and what a scenario looks like
4. [configuration.md](configuration.md) — `config.toml`, `settings.py`, environment variables, how to point components at different LLMs/prompts
5. [usage.md](usage.md) — day-to-day commands: install, generate data, run the prototype pipeline
6. [extending.md](extending.md) — how to add a new data generator, FoD extractor, mass function, or combiner via the registry pattern
7. [project_structure.md](project_structure.md) — annotated file/directory tree
8. [roadmap.md](roadmap.md) — what's implemented vs. planned
